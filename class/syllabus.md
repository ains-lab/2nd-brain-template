# 🎓 [강의계획서] AI 에이전트 기반 학술 데이터 자동화 및 2nd-Brain 구축

**과목명:** 자율형 AI 에이전트 구축 및 학술 데이터 분석 (*Autonomous AI Agents & Research Analytics*)

**수강 대상:** 컴퓨터공학 / 데이터사이언스 / 인공지능 관련 전공 (3~4학년)

**수업 형태:** 이론 1시간 + 실습/프로젝트 2시간 (주당 3시간)

---

## 📌 강의 개요

본 강좌는 Nous Research의 **Hermes Agent**와 **LLM Wiki(Andrej Karpathy 스타일의 컴파일형 지식베이스)** 패러다임을 활용하여, 본인의 연구 관심 분야에 맞는 **자율형 논문 수집·컴파일·핵심 요약·비교 분석 에이전트 시스템**을 구축하는 실습 중심의 과목입니다.

수강생은 단순한 LLM 프롬프팅을 넘어 **Docker 샌드박스 기반의 안전한 자율 코드 실행, 학술 API 연동, 양방향 링크 기반의 Obsidian 2nd-Brain 구축, Pydantic 기반 구조화 요약**까지 엔드투엔드로 구현하며, 기말에는 본인만의 자동화된 연구 지식베이스를 소장하게 됩니다.

## 📅 주차별 상세 커리큘럼

### 1단계: AI 에이전트 및 Hermes Agent 기초 (1주차 ~ 3주차)

- **1주차 | AI 에이전트 패러다임과 Hermes Agent 개론**
- **이론:** RAG/Chatbot과 자율 실행형 에이전트(Autonomous Agent)의 차이, Hermes Agent 아키텍처 이해
- **실습:** Hermes CLI 설치, LLM API(Gemini / OpenAI) 엔드포인트 연동 및 기본 실행 환경 설정

  
- **2주차 | Docker 및 Local Sandbox 실행 환경 구축**
- **이론:** 자율 코드 실행 시 시스템 격리(Docker Sandbox)가 필요한 이유 (안전성, 재현성, 자원 제한)
- **실습:** Docker Desktop 설치, 데이터 분석용 파이썬 컨테이너(`python:3.11-slim`) 환경 구성 및 Volume 마운트

  
- **3주차 | Hermes Agent 스킬 메커니즘 (Skill &amp; Skill Synthesis)**
- **이론:** 에이전트 지속 메모리, `agentskills.io` 표준 스킬 규격, 에이전트의 스킬 자율 합성 원리
- **실습:** 커스텀 분석 스킬(`.md`) 직접 작성, 에이전트에 등록 후 Docker 샌드박스 내부 실행 테스트



---

### 2단계: 대규모 학술 데이터 수집 파이프라인 구축 (4주차 ~ 6주차)

- **4주차 | 학술 API 기초 연동 (arXiv &amp; Semantic Scholar)**
- **이론:** 학술 API 구조 분석 (arXiv XML/Atom, Semantic Scholar JSON 및 인용 그래프)
- **실습:** Python `requests`를 이용한 특정 키워드 논문 메타데이터(제목, 저자, 초록, 피인용수) 수집 스크립트 작성

  
- **5주차 | 대규모 학술 데이터 수집 자동화 파이프라인 구축**
- **이론:** API Rate Limit 및 Exponential Backoff 전략, 중복 수집 식별(DOI, arXiv ID 핑거프린트), 비동기 I/O
- **실습:** `asyncio` 및 `tenacity` 기반의 비동기 수집 파이프라인 작성, SQLite/JSON 기반 중복 검사 및 상태 관리 구현

  
- **6주차 | 수집 자동화 에이전트 (Collector Agent) 패키징 및 테스트**
- **이론:** 자율 수집 에이전트의 예외 처리 및 Self-Correction (오류 자율 수정) Loop
- **실습:** 주제 입력 시 대규모 논문 다운로드부터 정제까지 한 번에 동작하는 Collector Agent 전용 스킬 구축

### 3단계: 2nd-Brain (LLM Wiki) 컴파일 구축 (8주차 ~ 10주차)

- **8주차 | Andrej Karpathy 스타일의 LLM Wiki 패러다임 &amp; Obsidian**
- **이론:** Vector RAG의 한계점 극복을 위한 컴파일형 지식베이스(LLM Wiki) 구조 이해
- **실습:** Obsidian Vault 디렉터리 설계 (`raw/`, `entities/`, `concepts/`, `comparisons/`, `queries/`, `SCHEMA.md`, `index.md`, `log.md`, `AGENTS.md`)

  
- **9주차 | LLM Wiki Compiler Agent 개발**
- **이론:** 수집 논문 본문에서 개념(Concept) 추출 및 교차 노트 생성, 양방향 링크(`[[Wiki-Link]]`) 작성 규칙
- **실습:** 새 논문 수집 시 기존 `wiki/concepts/` 노트를 자율 갱신/합성하는 Compiler Agent 구현

  
- **10주차 | 지식 그래프 시각화 및 Linting (지식 정화)**
- **이론:** 지식 그래프의 연결성, 고립 노드(Orphan Page) 처리 및 상충 정보 해결(Linting)
- **실습:** Obsidian 그래프 뷰(Graph View) 시각화 연동, 에이전트 기반 주기적 지식 정화(Linting) 스킬 구현



---

### 4단계: 핵심 요약, 분석 및 개인 프로젝트 (11주차 ~ 14주차)

- **11주차 | LLM Wiki 기반 논문 핵심 요약 및 정제 자동화**
- **이론:** 3대 핵심 구조 지표([1] 핵심 주장, [2] 알고리즘/데이터셋, [3] 차별점/한계) 추출 및 Pydantic Structured Output
- **실습:** `wiki/papers/` 내 논문 마크다운 노드에서 3대 핵심 항목을 자동 추출하여 프런트매터 및 상단에 파싱/업데이트하는 스크립트 작성

  
- **12주차 | 논문 비교 분석 및 연구 공백(Research Gap) 탐색**
- **이론:** LLM Wiki 지식베이스 기반 방법론 비교표(Comparative Matrix) 산출 및 미해결 연구 과제 도출
- **실습:** 특정 주제 논문들을 다각도로 비교 분석하여 종합 문헌 고찰(Literature Review) 보고서 자동 생성

  
- **13주차 | 개인 맞춤형 논문 분석 에이전트 파이프라인 통합**
- **형태:** 개인 프로젝트 코칭 &amp; 시스템 파이프라인 튜닝 (Lab &amp; Office Hours)
- **내용:** 수강생 개인별 연구 관심 분야 선정, 수집부터 LLM Wiki 컴파일, 3대 핵심 요약, 비교 분석까지 통합 튜닝

  
- **14주차 | 엔드투엔드 2nd-Brain 시스템 구축 및 기말 시험 대비**
- **이론:** 3~4단계(LLM Wiki 구조, Pydantic 요약 스키마, 비교 분석 메커니즘) 종합 서술형 이론 정리
- **실습:** 본인만의 2nd-Brain 파이프라인 최종 점검 및 기말 고사 핵심 개념 요약 정리
